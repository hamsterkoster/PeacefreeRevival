# 8. Game options: start speed, fullscreen, window sizes (medium)

Goal: Claude's suggestions "starting game speed" and "fullscreen button" ("Your suggestions sound good. Lets add 1-3 to the to do."), and "For 2, maybe we can have different window sizes?"

- Problem: every new act starts at 4x speed (`Map.as:232`, `mapHUD.changeSpeed(4)`; a loaded save keeps its own, `Map.as:405`); the game has 1x, 4x and 8x. The game has a fullscreen toggle (`PeacefreeGame.toggleFullScreen`, `PeacefreeGame.as:1037`), but the developer switched its title button off (`TitleScreen.as:162`, `if(false && ...)`); it stretches the game to the whole screen. The game's own Esc code (`PeacefreeGame.as:503-512`) never runs (it compares a string with the number 27); Flash Player leaves fullscreen on Esc by itself. The game doesn't scale with its window (`noScale`, `src/StarlingPreloader.as`): a bigger window shows the 800x540 game in its top-left corner. Flash Player can't resize its own window from ActionScript (only Adobe AIR can).
- Read first: those lines; `MapHUD.changeSpeed` (`MapHUD.as:585`); `resizeStage`/`resizeBack` in `src/StarlingPreloader.as` and the `handleLostContext` decision; `SoundLibrary.saveVolumes` (the `settings` save to extend); `CampaignSelectorScreen.startAct` (where a new act starts); docs/local.md (the projector's path and run command).
- Approach (decided 2026-10-31, docs/decisions.md): a "Start Speed" row (1x / 4x / 8x) in the options panel on all three screens, saved in `settings`, applied in `CampaignSelectorScreen.startAct` (not to Act 1, the tutorial, which hides the speed buttons); the game scales to fit its window (black bars, its own shape, at most 2048 wide), and a Fullscreen/Windowed button in the panel; no launcher.
- Answers (the user, all suggested): start speed default 4x; scale with the window, no launcher; fullscreen with black bars; `check.py --mission` built in step A.
- Test: the headless checks pass; `--settings` also clicks 1x and reads the save; a new `check.py --mission` sets 1x, unlocks all acts, starts Act 2 (Act 1's tutorial hides the speed buttons) and checks the HUD's 1x button is lit. In the projector: a new act starts at the chosen speed; the game fills a dragged or maximized window and fullscreen on both monitors; Esc leaves fullscreen and the game keeps running.
