# 9. Controls: a list of the mission keys, then rebindable keys (large)
Goal: "Controls list might even have customizable hotkeys instead, if possible."
- Problem: missions have about 10 keyboard shortcuts in a fixed `switch` (`Map.onKeyDown` and `onKeyUp` in `src/game/peacefree/Map.as`; key codes 192 for the backtick, 81 Q, 70 F, 69 E, 82 R, 84 T, 71 G, 88 X, 67 C and more), plus our P for the FPS box (`src/StarlingPreloader.as`) and Esc to leave fullscreen (`PeacefreeGame.as:503-512`). ~~Claude found nowhere the game shows them~~ Wrong (step A): the game shows most of them, each in one place (tooltips, the minimap, menu options, tutorial lines); never the arrow keys, the backtick, P or Esc. Details: "Keys" in docs/research/game-code.md.
- Read first: those functions and what each key does (follow each `case`); `PeacefreeGame.onKeyDown`/`onKeyUp` (`PeacefreeGame.as:491-499`); `OptionsInterfacer` (the panel a Controls page opens from); the `settings` save (`SoundLibrary.saveSettings`); "Keys" in docs/research/game-code.md.
- Approach, in steps: A, a "Controls" button in the panel opening a page that lists each key and what it does (read-only). B, rebindable keys: each row's key is a button that waits for the next key press; the bindings go in the `settings` save; `Map.onKeyDown`/`onKeyUp` look keys up in the bindings instead of fixed codes; a "Reset to defaults" button.
- Ask the user (B): build B at all, decided after seeing A (cost: about 15 in-game texts in 6+ classes name fixed keys, such as "Rush Command [Q]", `[W][A][S][D]` on the minimap and "[1]" before menu options, and would show the wrong key unless patched too); a key already in use (suggested: the two actions swap keys); P and Esc (suggested: not rebindable, only the mission keys); 1-9 (suggested: not rebindable, the menus show them).
- Test: the headless checks pass, plus a `--settings` step that opens the Controls page; in the projector, the list matches what the keys do, and (B) a rebound key works in a mission and after a restart.
